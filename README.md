# Data to support the paper "A Compositional Calculus for Semantic Synergy in Language Model Embeddings"

`idiom_literal_pairs.csv` contains the 107 paired idioms and literals with their meanings. 
`idiom_literal_pairs_extended.csv` contains the LLM-extended list of 836 pairs. 
`names.csv` contains the names used in the compositional vs non-compositional name analysis.
